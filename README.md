## About Me

I'm an AI/ML developer from Kanpur, India, currently in my 4th semester of B.Tech CSE (AI & ML) at MIPS Kanpur, graduating in 2028. I build systems end-to-end — from raw packet bytes to production ML pipelines — and I care more about *why* a solution works than which library gets me there fastest.

My work spans deep packet inspection, applied NLP, LLM-powered agents, and computer-vision-driven backend intelligence. I favor zero-dependency, first-principles builds over black-box shortcuts, and I document my systems the way I'd want to read them.

```python
def my_edge(problem):

    step_2 = design_the_logic_on_paper(step_1)          # most skip this too
    step_3 = implement_clean_and_modular(step_2)
    step_4 = iterate_until_it_actually_works(step_3)
    return step_4
```

## How I Approach a Problem

Most developers ask *"what tool solves this?"* I ask *"what is this problem actually doing, what has to be true for a solution to work, and what breaks if I'm wrong?"*

That mindset applies the same way to a DSA problem as it does to a full ML pipeline — it's slower to start and faster to finish.
