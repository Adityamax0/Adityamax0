## 🚀 Featured Projects

### 1. 🔎 DPI Engine (Deep Packet Inspector)
> **Raw-Socket Packet Parser & Traffic Classifier**
* Built a custom packet parser that reads TCP/IP frames without heavy extra libraries.
* Identifies TLS SNI across **50+ apps in real-time** and uses a **Random Forest model** if headers are hidden.
* Includes a live Flask dashboard and PCAP file replay feature.
* **Tech:** `Python`, `Scapy`, `scikit-learn`, `Flask`

---

### 2. 🌾 SCAS (Smart Crop Advisory System)
> **Offline-First Agritech Advisory Engine**
* Built a system for farmers in low-internet areas using MongoDB `2dsphere` location matching.
* Uses `Llama-3.2 Vision` for plant disease check from photos and `Whisper` for voice queries.
* Features automatic SLA escalation to handle ticket routing smoothly.
* **Tech:** `Node.js`, `MongoDB`, `Groq Cloud API`, `Docker`

---

### 3. 📄 Scholar-Agent Pro
> **Multi-Agent Research Paper Analyzer**
* Uses **12 AI agents** to break down research papers into short summaries and extract LaTeX math formulas.
* Includes a built-in reviewer agent to double-check claims and research results.
* Powered by fast zero-cost inference via Groq LLaMA 3.3.
* **Tech:** `Python`, `Streamlit`, `Groq API`, `PyMuPDF`

---

### 4. 🎯 LENS (Layout Error Navigation System)
> **Self-Healing UI Auditor**
* Automatically checks website UI for broken styles, wrong hex colors, and hardcoded CSS bugs.
* Compares screenshots using headless Chrome (`Puppeteer`) and `pixelmatch`.
* Automatically rewrites broken CSS code back to correct design tokens.
* **Tech:** `Node.js`, `Puppeteer`, `pixelmatch`, `Babel AST`

---

### 5. 💬 MEMET

* **Tech:** `FastAPI`, `Groq API`, `Vanilla JS`, `Docker`
